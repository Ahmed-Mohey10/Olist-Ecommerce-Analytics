# Olist E-commerce Analytics

E-commerce data analysis project using SQL Server and Power BI, based on the Brazilian Olist e-commerce dataset.

## Project Overview

This project analyzes e-commerce sales, customers, products, sellers, and payment data to generate meaningful business insights.

The analysis was performed using SQL Server for data analysis and Power BI for interactive dashboards and data visualization.

## Business Questions

- How are sales performing over time?
- Which states generate the highest sales?
- Which product categories sell the most?
- How many customers are there, and how many are repeat customers?
- Which states and cities have the most customers?
- Which sellers generate the highest sales?
- What payment methods are most commonly used?
- How does payment value vary across different payment methods?

## Dashboard

The Power BI dashboard consists of three analytical pages:

### 1. Sales Performance

- Total Sales

### 2. Customer & Product Analytics
Focuses on:
- Customer Distribution
- Customers by State

- Repeat Customers

### 3. Seller & Payment Performance
Focuses on:
- Seller Performance
- Seller Sales Contribution
- Items Sold by Seller
- Payment Methods
- Payment Value
- Payment Transactions
- Installment Analysis
